# 旧样式使用指南迁移说明

此旧路径保留用于兼容历史链接。旧示例引用了已变更的 CSS 变量、混入和目录路径，不应直接复制到当前组件。

按任务使用以下现行入口：

- 强制样式规范总览：[前端规范索引](../frontend/INDEX.md)。
- 颜色令牌与债务门禁：[后台统计卡片颜色规范](../frontend/admin-stat-card-color-standard.md)。
- 页面骨架与后台布局：[统一页面结构规范](../frontend/unified-page-structure.md)。
- 表格、按钮、对话框与分页：分别见[表格规范](../frontend/admin-table-standards.md)、[按钮规范](../frontend/button-standards.md)、[对话框规范](../frontend/dialog-standards.md)、[分页规范](../frontend/pagination-standards.md)。
- 移动端交互：[移动端开发标准](../guides/mobile-development-standards.md)。

新增或调整强制要求时，依照[规范审计接入指南](../frontend/standards-audit-guide.md)同步规范正文、公共实现、自动检查和 `standards-manifest.json`。
