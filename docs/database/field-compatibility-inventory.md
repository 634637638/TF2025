## 模拟数据与硬编码清理（2026-08-28）

营销天气、库存统计、H5 首页推荐和系统站点资料已完成伪数据清理：天气或统计不可用时保持空值/不可用状态，H5 只读取后台明确配置的商品，站点设置不再提供真实公司样例。此次未删除数据库数据，也未修改数据库物理字段。

本清单记录 API 规范字段与历史字段之间的临时兼容。兼容字段只能出现在后端边界映射或一次性迁移代码中，不能进入前端新请求、业务计算或数据库新写入逻辑。物理字段迁移和真实数据回归完成后，必须删除对应条目。

### 字段控制补充（2026-08-28）

## 字段权限覆盖登记（2026-08-28）
