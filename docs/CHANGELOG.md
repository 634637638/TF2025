## [2026-10-04] - 客户手机号检索云端分页兼容修复

- 修复批发、划拨、销售和综合查询快速出库在云端检索客户手机号时“搜索中后空白”的问题。
- 根因是 MySQL 预处理语句对 `LIMIT ? OFFSET ?` 参数返回 `ER_WRONG_ARGUMENTS`，导致 `/sales/customers` 返回 500。

- 当前云端数据库只读验证返回 `total=565`、首批 `50` 条，后端语法检查通过。
- 更新客户检索规范和公共检索实施台账；云端部署后需重启后端，并完成四个业务入口的真实回归。
