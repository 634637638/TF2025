# 新品预定权限与库存联动规则

## 权限定义

| 权限 | 页面操作 | 后端接口 | 业务结果 |
| --- | --- | --- | --- |
| `preorders_preordersview:match` | 匹配 | `GET /api/preorders/:id/matchable-phones`<br>`PUT /api/preorders/:id/match` | 为待匹配预定单选择库存设备，设备标记为已预定 |
| `preorders_preordersview:deliver` | 交付 | `PUT /api/preorders/:id/deliver`<br>携带 `preorder_id` 的 `POST /api/sales/phone` | 通过销售出库交付已匹配设备，预定单变为已交付 |
| `preorders_preordersview:cancel` | 取消 | `PUT /api/preorders/:id/cancel` | 取消预定单；已匹配设备清除绑定并恢复为可售状态 |

`edit` 用于编辑交付前的待匹配或已匹配预定单，以及恢复已取消预定单；`delete` 只用于删除允许删除的历史记录，不得代替 `match`、`deliver` 或 `cancel`。

## 匹配规则

1. `pending` 状态的预定单可以手动匹配；`arrived` 状态且未交付的预定单可以更换匹配设备。
2. 可选设备必须是 `status = in_stock` 或历史遗留的 `reserved` 状态，且没有被其他有效预定占用；当前订单原绑定的设备可以继续展示，便于确认或更换。
3. 设备的品牌、型号、颜色、内存、机况必须与预定单当前字段完全一致，预定店铺不限制实际匹配设备所在店铺。
4. 匹配在同一数据库事务内锁定预定单和设备，同时写入 `matched_phone_id`、IMEI 和匹配时间，防止并发重复占用；更换设备时先释放原设备，再占用新设备。
5. 新增预定时的自动库存联动属于系统流程；用户主动打开匹配列表、更换或确认设备时必须校验 `match` 权限。

## 重新匹配与恢复

1. 已匹配预定单编辑品牌、型号、颜色、内存或机况时，视为重新匹配。原设备必须在同一事务中解除 `is_preordered` 占用，预定单状态改回 `pending`，并清空 `matched_phone_id`、IMEI、匹配时间、实际型号、到货日期和实际价格。
2. 编辑后的订单只能使用最新商品规格查询匹配设备；库存查询不限制返回数量，只有 1 条符合条件的设备时也必须展示并允许选择。
3. 取消预定会清除订单绑定，并将没有其他有效预定占用的原设备恢复为 `in_stock`；恢复取消订单时也会清理残留绑定，然后按当前商品规格自动匹配最早可用库存，匹配成功恢复为 `arrived`，无库存时恢复为 `pending`。
4. 后续入库命中当前商品规格时，系统可按创建时间自动匹配最早的待匹配订单；未自动匹配时可从匹配窗口手动选择。

## 交付规则

1. 只有 `arrived` 状态且已关联设备的预定单可以交付。
2. 交付必须通过预定单已匹配的同一台设备，不允许用其他库存设备替换出库。
3. 从预定单页面点击“交付”时需要 `preorders_preordersview:deliver`；从销售管理或库存管理出库时需要对应模块的 `sell`（出库）权限。预定客户、匹配设备和预定状态仍由后端统一校验。
4. 权限不足、预定状态不对或设备不一致时，后端必须拒绝请求并回滚销售事务。

## 前端接入规范

- 页面使用 `usePagePermissions('preorders')` 提供的 `canMatch`、`canDeliver`、`canCancel`。
- 操作列宽度使用 `getAdaptiveActionColumnWidth` 按当前状态和权限计算。
- 模态框使用全局 `MobileDialog`，表格使用全局 `el-table` 类名，不在页面内重复定义按钮和表格基础样式。
- 前端的 `v-if` 只负责交互展示，后端接口必须继续使用 `requirePermission` 作为最终边界。
# 人员字段与销售联动

- `created_by` 记录预定人。新建预定单默认使用当前登录账户姓名，也可以在有权限时选择其他在职人员。
- `operator_id` 只记录完成交付的销售员。已交付列表统一显示为“销售员”，不再显示“操作员”。
- 预定单创建、匹配和交付不会覆盖预定人；交付销售员通过销售记录关联。
- 销售员在销售管理或综合查询中修改后，系统同步更新已交付预定单的销售员，因此各页面显示一致。
- 预定表单顶部统一展示手机号、客户姓名、销售店铺和预定人；销售店铺是实际出库时使用的店铺，可与库存设备所在店铺不同。
