## 使用规则

1. 当前状态只在历史兼容接口退役台账和全局技术债务 T6 中维护；本目录是删除证据和恢复记录，不建立第二份当前待办。
2. 删除前恢复标签统一为 `compat-routes-before-removal-20261104`；不得再建立源码备份目录或复制运行时实现。
3. 删除提交形成后同步填写删除 commit；部署后补充观察时间、旧路径 404、访问来源、受影响页面和回滚结果。
4. 出现旧路径访问或页面错误时，先按 `migration_id`、request ID、用户 ID 和 User-Agent 定位，再回滚对应删除提交；不得从归档复制代码形成长期并行实现。
5. 日志不得记录 Token、Cookie、请求体、搜索关键词或其他敏感数据。
