# 全局下载与文件预览安全规范

> 版本：v1.0.0
> 适用范围：所有前端页面、公共组件、上传后的文件预览和文件下载

## 强制规则

1. 私有业务文件禁止直接使用 `/uploads/...` 作为前端下载或预览地址。文件必须经过后端受控接口，由后端完成登录、角色、数据归属、状态和文件存在性校验。
2. 前端文件下载统一调用 `unifiedApi.download()`；页面不得自行创建第二套 Axios 实例或重复实现 Blob 下载逻辑。
3. 图片预览与普通文件下载分开处理：图片使用统一媒体预览组件或受控 `inline` 响应；PDF、Office、文本和压缩文件使用 `attachment` 下载。
4. 下载接口必须设置 `X-Content-Type-Options: nosniff`、`Cache-Control: private, no-store`，并使用服务端记录的 MIME 与安全文件名。不能信任前端传入的路径、扩展名或文件名。
5. 签名凭证必须短时有效、使用服务端密钥生成、使用常量时间比较校验；凭证应通过请求头传递，不得放入 URL 查询串，也不得写入业务日志。
6. 删除、替换业务记录时必须按数据库关联清理物理文件，不能留下可被猜测或重复使用的孤立文件。
7. HTTPS 只能保护传输过程。文件已经成功交付给用户后，无法阻止用户保存、复制或转发；需要更高等级防护时应增加水印、审计和访问次数策略。

## 公开资源例外

商品公开图片、商城公开媒体、品牌图片等明确用于公开展示的资源，可以继续使用公开静态资源地址。例外必须在页面台账中登记“公开展示”，并且不能混用私有附件目录。导航站文件、国补材料、维修媒体、租赁合同、备份文件、经验分享附件均按私有文件处理。

## 当前统一入口

| 场景 | 前端入口 | 后端访问方式 | 安全要求 |
| --- | --- | --- | --- |
| 导航站 `/DH` 文件 | `unifiedApi.download()` / 统一图片预览 | `/api/public/guide/files/:id`；密码分类额外短时签名 | 分类和连接启用校验、文件关联校验；密码分类校验短时凭证 |
| 租赁合同 | `unifiedApi.download()` | 租赁记录归属接口 | 登录、租赁记录归属 |
| 备份文件 | 备份公共下载入口 | 一次性/短时下载令牌 | 管理权限、令牌校验 |
| 经验分享附件 | 共享附件入口 | 共享文件受控接口 | 登录、分享记录归属 |
| 维修媒体 | 维修媒体入口 | 维修记录受控接口 | 登录、维修记录权限 |
| 国补材料 | 国补媒体入口 | 国补文件受控接口 | 登录、国补记录权限 |
| 导出文件 | `unifiedApi.download()` 或统一导出服务 | 导出接口 | 页面权限、字段权限和审计 |

## 页面台账要求

任何新增或修改下载能力，必须在《前端页面与功能单元台账》的“下载安全专项登记”中记录：页面路由、文件类型、前端入口、后端接口、是否公开、权限要求、归属校验、缓存策略和删除生命周期。未登记不得通过审计。

## 禁止事项

- 禁止把 `/uploads` 物理路径拼接到页面中。
- 禁止将永久下载令牌写入数据库响应、URL 收藏地址或日志。
- 禁止使用 `window.open`、原生 `fetch` 或页面私有 Blob 工具绕过统一下载入口。
- 禁止仅根据文件扩展名决定是否为图片；优先使用服务端 MIME，扩展名只能作为上传校验的一部分。
