# 主题切换规范

Pinia `app` store 是主题偏好的唯一状态来源。`light`、`dark`、`auto` 最终都由 `applyTheme()` 解析为当前有效的 `light` 或 `dark`，并写入 `<html data-theme>`；CSS 主题令牌只按该属性切换。业务组件不得另行直接修改根节点主题 class 或创建第二份主题状态。

新增颜色优先使用语义 CSS 变量，并同时检查亮/暗主题下的文本对比、边框、遮罩和状态色。没有暗色令牌的历史组件属于迁移债务，不得因此复制一套页面级主题切换逻辑。

```bash
cd frontend
npm run check:theme
```

当前审计保证主题状态与 CSS 令牌入口连接，不表示每个业务页面都已完成暗色模式视觉验收。
