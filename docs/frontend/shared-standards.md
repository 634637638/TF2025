# Shared 经验分享规范

## 功能边界

`/shared` 用于沉淀问题处理经验、操作记录和公共文档。所有已登录用户都可以查看公开分享并发布内容；发布者可以编辑、删除自己的内容。拥有 `shared:manage` 的管理员可以维护分类、编辑和删除全部公开内容，并执行置顶/取消置顶。

普通用户发布的内容固定为公开，不能通过前端参数或直接调用接口创建私有内容。只有拥有 `shared:manage` 的用户可以把自己发布的内容设为私有；私有内容只允许发布者本人查看、编辑和删除，其他普通用户及其他管理员均不可越权访问。管理员编辑他人公开内容时不能把该内容改成私有。

每条分享包含标题、分类、可见范围、富文本正文、发布者、发布时间、置顶状态和媒体元数据 JSON。图片和视频通过富文本工具栏直接插入正文，文件本体保存在 `uploads/shared`，数据库只保存 URL、原文件名、MIME 类型和大小，避免把大文件写入数据库。旧文章自动兼容为“未分类、公开”。

## 富文本正文

新增和编辑使用 Vue 3 的 wangEditor 完整富文本编辑器。正文支持段落和多级标题、引用、加粗、斜体、下划线、删除线、字体字号、文字/背景颜色、行高、有序/无序列表、待办、对齐、缩进、表情、链接、图片、视频、表格、代码块、分割线、撤销重做和全屏等组合内容。图片和视频使用富文本工具栏上传；其他资料使用编辑器底部的“插入文件”，上传后在光标位置生成下载链接。编辑表单不再提供独立附件区域，避免入口和展示内容重复。编辑区在手机端自动换行且工具栏允许换行，不能产生页面横向溢出。

富文本编辑器首次创建时必须显示短暂的就绪反馈。用户在初始化完成前点击编辑区域时，应记录聚焦意图并在编辑器创建完成后立即自动聚焦，不能吞掉首次点击或让界面表现为无响应。

新增、编辑弹窗使用全局 `tf-dialog-form tf-dialog-form--stacked`，保留“标题”和“内容”标签并显示在字段上方，使标题框和富文本编辑器占满正文可用宽度、左右间距完全一致。正文左右内边距必须使用全局 `_dialog.scss` 的相同变量，Shared 页面不得单独覆盖。

富文本必须在保存前和显示前分别净化。后端只保留约定的排版标签；链接只允许 `http` 和 `https`，并强制使用 `noopener noreferrer`。前端详情使用 `DOMPurify` 再次净化后通过 `v-html` 渲染。列表摘要不能直接截取 HTML，必须先提取纯文本。旧的纯文本内容继续兼容显示。

## 数据模型

经验分享使用文章表 `shared_posts` 和精简分类表 `shared_categories`。文章核心字段为：

- `title`：经验标题；
- `content`：经过净化的富文本正文；
- `attachments`：正文上传媒体及历史附件元数据 JSON；
- `category`：管理员维护的分类名称；
- `visibility`：`public` 公开或 `private` 私有；
- `is_pinned`：置顶状态；
- `author_id`：发布用户。

`shared_categories` 只保存 `id`、`name` 和 `sort_order`。分类由拥有 `shared:manage` 的管理员新增、重命名和删除，普通用户只能选择，不能自由输入。默认“未分类”不能编辑或删除；删除其他分类时，该分类下文章自动迁移到“未分类”。启动升级时会将已有文章分类迁入分类表，不丢失历史分类。

正文上传媒体和文件合计最多 10 个，单个文件最大 100MB。支持图片（JPEG、PNG、GIF、WEBP）、视频（MP4、WEBM、MOV）、PDF/OFD、Office/WPS、TXT/Markdown/RTF、CSV/JSON/XML、ZIP/RAR/7Z/TAR/GZ/BZ2、EPUB 以及 MP3/WAV/M4A/AAC/FLAC。禁止 EXE、APK、DMG、BAT、SH、HTML、JS 等可执行或脚本格式。旧分享中的非正文附件仍可查看下载。文件名由后端随机生成，不使用用户原始文件名作为磁盘路径。

## 列表和详情

列表按置顶优先、发布时间倒序排列。PC 端使用紧凑卡片网格，一行 3 条；中等宽度一行 2 条；手机端一行 1 条。卡片显示分类标签；仅发布者本人能看到自己的私有标签。卡片只显示标题单行缩略、正文两行摘要、媒体数量、发布者和发布时间，正文摘要最多保留约 96 个字符，详情页显示完整内容。卡片点击即可打开详情，顶部不重复显示“查看”按钮；编辑、删除、置顶等权限操作按权限保留。正文图片点击后使用图片预览器查看并可切换同文图片，视频显示原生控制条播放器，音频链接在详情渲染时转换为原生音频播放器。正文媒体不能在详情底部重复展示；历史上未嵌入正文的图片、视频和音频分别使用预览或播放器，其他附件继续显示文件名、大小和下载入口。

卡片权限操作是全站操作按钮的参考实现：容器使用 `.action-buttons`，按钮使用 `.table-action` 和显式语义 class；编辑使用 `.table-action--edit`，删除使用 `.table-action--delete`，置顶使用 `.table-action--pin`。尺寸、背景、边框、文字、悬停及禁用状态全部读取 `admin-layout.css` 和 `_table.scss` 的公共规则。Shared 页面只控制按钮排列，不得重复维护视觉值，也不得把单个按钮背景拉伸占满操作栏。分类管理中的编辑和删除使用同一规则。

图片预览器必须使用 Element Plus 的 `teleported` 挂载到 `body`，并加载 `element-plus/theme-chalk/el-image-viewer.css` 官方样式；同时使用高于普通弹窗的公共层级 `--tf-image-viewer-z-index: 12000`，确保从详情弹窗打开时遮罩、图片和缩放工具栏完整覆盖在最上层。

详情弹窗中的标题信息区和正文区必须使用不同背景及清晰边界，帮助用户区分文章信息与正文，但不使用左侧彩色装饰条，并保持紧凑、克制。正文、表格和媒体优先在弹窗可用宽度内自适应，不得撑宽或超出弹窗。富文本表格必须完整保留表头背景、单元格边框、内边距、对齐和换行效果；只有内容确实无法继续收缩时，才由正文区域提供横向滚动，PC 鼠标/触控板和手机触控均可左右移动，表头与表格内容必须同步移动，不得用省略号隐藏单元格内容。

详情标题下的头像、发布者和发布时间默认横向一行展示；窄屏空间不足时允许整体自然换行，不得将发布者和发布时间强制堆叠成上下两行。
详情中的文章标题统一居中显示，发布者信息仍在标题下方按原有方式排列。

页面使用全局后台结构和公共间距变量；经验分享是内容流，不使用伪造的表格列或独立的手机卡片体系。手机端正文自然换行，附件网格在窄屏自动变为单列。

列表检索必须使用全局 `UnifiedSearchPanel`，主输入框搜索标题和正文，并支持与分类组合筛选，使用公共搜索、重置按钮及加载状态。管理员额外显示“全部可见内容 / 公开分享 / 我的私有”范围筛选；普通用户只会获得公开结果，不显示无效的私有筛选。Shared 页面不得维护独立搜索面板背景、间距、按钮尺寸或手机端排列规则。

详情和编辑弹窗底部统一使用全局 `tf-dialog-actions`：PC 端按钮自适应内容并靠右，手机端按钮等宽保持一行。Shared 页面不得再维护独立的按钮宽度规则。

## 编辑、删除和置顶

- 发布者只能编辑和删除自己的分享；
- `shared:manage` 可编辑、删除他人的公开分享，以及自己的私有分享；
- 只有 `shared:manage` 可以置顶；
- 删除分享时同步清理该分享仍引用的附件文件；
- 编辑时只清理被移除的附件，保留仍在正文中的附件；
- 任何权限判断都必须由后端再次校验，前端按钮隐藏不能代替接口鉴权。
- 普通用户发布和编辑时，可见范围由后端强制为公开；
- `shared:manage` 只允许设置自己文章的公开/私有状态；
- 私有文章不能置顶，管理员也不能查看、编辑或删除他人的私有文章；
- 分类新增、重命名、删除接口全部要求 `shared:manage`，发布接口只接受分类表中现存的分类。

模块权限注册在 `shared_sharedview`：`view`、`create`、`edit`、`delete`、`manage`。页面路由 `/shared` 需要 `shared:view`；发布需要 `shared:create`；编辑和删除自己的内容分别需要 `shared:edit`、`shared:delete`；管理员拥有 `shared:manage` 后可以维护分类、管理公开内容、管理自己的私有内容并执行置顶。卡片点击即可查看，操作区按权限显示“编辑、删除、置顶”，按钮显隐只是体验层，后端接口会再次校验权限、作者归属和可见范围。

## 上传安全

上传接口为 `POST /api/shared/upload`，使用 `multipart/form-data` 的 `files` 字段。后端限制扩展名、MIME 类型、文件数量和单文件大小，附件目录固定在上传根目录下的 `shared` 子目录，禁止路径穿越。

`/uploads/shared/*` 禁止静态直连，正文和附件展示统一转换为 `/api/shared/files/:filename` 受保护地址。文件接口必须校验登录和 `shared:view`，再检查附件所属文章：公开文章附件可由有查看权限的用户读取，私有文章附件仅发布者本人读取。尚未保存的上传文件只允许文件名中记录的上传者预览；前端不得把会话令牌永久写入数据库正文。
