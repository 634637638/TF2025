# 导航站 `/DH` 与 `/guide` 规范

## 入口职责

- `/DH`：公开访问的移动端优先导航页，不要求登录。
- `/guide`：后台导航管理页，必须通过统一路由守卫、`PermissionGate` 和后端 RBAC。
- 公共 API 使用 `/api/public/guide`；管理 API 使用 `/api/guide`。

## 功能边界

- 公告支持启停、排序、有效时间和可选跳转链接。
- 公告展示分为两个独立卡片：置顶公告固定在上方，非置顶公告在下方卡片中轮换；普通公告默认每 4 秒整条切换一次，不使用连续平滑滚动。没有对应公告时不渲染空卡片。
- 公告标题居中显示，正文位于标题下方；正文首行保留 `2em` 缩进，换行后的正文从正文区域起始位置对齐。
- 分类支持公开访问和密码访问。
- 分类层级支持两级：一级分类下可维护二级分类，二级分类仅为标题，不是连接、不可跳转；禁止三级分类。一级、二级分类均必须通过后台“编辑”维护名称，前台和后台不得显示写死的“一级分类”“二级分类”作为分类标题。连接通过“所属分类”绑定到任意一级或二级分类，编辑时可改绑，公开页在相应分类标题下展示连接。
- 后台分类卡片和公开导航分类内容均使用全局 `tf-page-tabs`（分类场景可显式增加 `tf-page-tabs--compact`）：一级分类使用其实际名称作为默认标签，二级分类使用其实际名称作为独立标签，公开页的标签紧邻一级分类标题并在空间不足时换行；全局 TAB 默认按钮尺寸已与表格操作小按钮一致，连接按钮按内容自适应宽度，不得使用大卡片式高度；点击标签后仅展示当前分类的连接。公开页每个分类全部加载连接，但连接区域默认按约 6 行的高度显示，超出后在区域内上下滚动查看，不限制后台实际保存总数；公开页连接按钮限制最大宽度并自动换行，避免短标题被拉伸占满列；后台连接网格按最小卡宽自动换列。连接名称和说明允许完整换行，不以单行省略裁切。连接卡片不显示额外的连接/二维码图标和箭头，网址连接直接跳转，二维码连接打开统一二维码弹窗。
- 后台新增/编辑连接的“分类”统一使用 Element Plus `el-tree-select`：一级分类为根节点，二级分类为可展开子节点，节点标签只显示实际分类名称，不添加“一级分类/二级分类”前缀；一级和二级节点均可绑定连接。分类新增/编辑的“所属一级分类”只允许选择一级节点，禁止形成三级分类。
- 分类 TAB 的最大宽度为分类卡片的可用宽度，前台和后台的承载 Grid 必须允许收缩；标签过多时使用全局原生横向滚动，不显示左右箭头或滚动条，也不得撑宽分类卡片。标签切换只改变当前分类内容，不改变卡片宽度；尺寸和滚动行为遵守 [TAB 统一规范](tab-standards.md)。
- 公开页存在二级分类时，一级分类同名 TAB 仅在该一级分类有可见直属连接时显示；无直属连接时默认选择第一个二级分类，避免先显示空的同名标签及“暂无导航”。一级分类标题始终保留，密码锁定时仍显示锁图标与“仅会员可见”；解锁后重新校验当前标签并展示有效分类内容。没有二级分类且没有连接时仍显示“暂无导航”。后台管理保留一级分类 TAB，以便新增、维护直属连接。
- 后台分类和连接表单的“图标、状态、排序”使用同一行三列布局，手机端按公共响应式规则收为单列；状态字段保留“状态”标签，`el-switch` 不重复显示“启用/停用”按钮文字，列表状态徽章继续显示“启用/停用”。
- 导航支持外部网址和文件两种类型；文件上传统一支持图片、PDF、Office 文档、文本/表格、Apple `.mobileconfig` 配置文件、APK/IPA 安装包、常见音频（MP3、M4A、WAV、FLAC、OGG）、常见视频（MP4、MOV、AVI、MKV、WebM、3GP）和压缩包。服务端只存储并以附件方式交付，不执行或解析安装包、音频、视频和未知二进制内容；EXE、脚本、HTML/SVG 仍禁止。图片点击后使用公共图片弹窗查看，其他文件通过 `unifiedApi.download()` 下载；已保存文件不得使用 `/uploads/guide/...` 直链。
- 公开分类直接返回启用的导航；密码分类只返回名称、说明和锁定状态。
- 后台管理预览/下载使用登录态和 `guide:view` 权限，可查看已停用但仍保留的文件；公开文件接口仍只允许启用的导航，不能因后台例外放宽公开访问。
- 受保护分类的密码只保存 bcrypt 哈希，不向前端、日志或接口响应返回。

## 密码策略

| 策略 | 服务端有效期 |
| --- | --- |
| 一次性 | 令牌最多成功使用一次，令牌本身五分钟后失效 |
| 一天 | 24 小时 |
| 自定义天数 | 1 至 3650 天 |
| 一个月 | 30 天 |
| 一季度 | 90 天 |
| 一年 | 365 天 |
| 永久 | 不设置过期时间，但分类密码被修改后旧令牌立即失效 |

解锁后由服务端签发分类访问令牌，并记录令牌哈希、分类、过期时间和剩余次数。前端权限状态不是安全边界。

## 上传与删除

- 导航文件统一存放在 `uploads/guide/`，使用随机文件名，数据库通过 `file_url`、`file_name` 和 `file_mime` 保存存储地址、原始名称和服务端 MIME；公开分类通过公开文件接口访问，密码分类通过短时签名接口访问。
- 导航文件采用暂存保存模式：上传生成草稿文件，点击保存导航后才转为正式文件；关闭、取消、替换文件或保存失败时，前端必须复用 `temp-file-cleaner` 调用公共临时文件清理接口，不能直接拼接路径删除；服务端定时清理超时草稿。
- `uploads/guide/` 必须位于持久化磁盘或共享文件存储中，不能随代码发布、容器重建或后端重启被清空；数据库和文件目录必须使用同一后端环境。开发环境连接云端数据库时，不得直接假定本机 `uploads/guide/` 具备云端文件，文件缺失时接口必须安全返回 404，并通过后台重新上传恢复。
- 单文件不超过 30 MB，服务端按扩展名和 MIME 双重校验，禁止可执行文件与 HTML/SVG。
- 修改文件时删除旧文件；删除导航时删除其文件；删除分类时先读取并删除该分类全部文件，再删除数据库记录。
- 不复用商城模板图片目录，也不把用户输入直接拼接成文件路径。

## 权限

模块能力登记为 `guide_guidemanagementview`：`view` 查看，`create` 新增，`edit` 编辑/排序/启停/密码策略，`delete` 删除，`upload` 上传文件。后端管理接口必须使用 `unifiedAuth` 和对应 `requirePermission`。模块权限会在启动 schema 检查时幂等注册到模块表；菜单入口仍按既有菜单管理流程创建并关联模块。

## 前端接入

前台使用移动端优先布局，重点验证 360px、390px 和桌面宽度。页面接入统一 API、统一弹窗、统一按钮、统一响应式消息和类型定义，不在页面内新增第二套权限或请求实例。

专项检查：

```bash
cd frontend
npm run type-check
npm run check:permissions
npm run check:backend-security
```
# 导航站设置与客服

`/guide` 的“设置”统一维护 `/DH` 的公开展示配置：顶部副标题、导航标题、底部信息、客服微信和客服电话。三个展示文字独立保存，分别使用统一类型 `GuideSettings` 的 `site_eyebrow`、`site_title`、`footer_text`，默认值为 `DH NAVIGATION`、`导航中心`、`DH Navigation`；均为必填、最多 120 字符。前台通过接口展示文本，长文字在 360px 手机端自动换行，不得通过页面硬编码覆盖配置。配置由后台权限 `guide:view` 查看、`guide:edit` 修改。导航连接的文件上传流程与客服设置分离。

`/DH` 通过公开导航接口实时读取设置，接口使用 `Cache-Control: no-store`。客服入口固定在视口底部导航上方，视觉与商城一致：绿色 `56px` 圆形耳机图标在上、“客服”文字在下，外层背景透明，无矩形底或文字胶囊；右侧 `16px`、底部 `148px`，由全局令牌控制尺寸和定位。入口使用公共 `tf-button--service-float`，弹窗联系方式使用公共 `tf-button--service-card`，不得继承普通按钮固定高度或在页面重复定义按钮表面。拨打和加微信卡片并列且等高，最小高度 `144px`；只有单项时使用同一规格，长内容允许增高并完整换行。电话使用 `tel:`，微信点击后先复制微信号，再尝试通过 `weixin://dl/chat` 唤起客户端。协议唤起受浏览器、操作系统和微信安装状态限制，失败时提示用户手动添加。客服二维码不属于导航站设置或联系方式展示。

客服设置只维护微信号和电话号码，不得增加客服二维码上传、读取接口或孤立文件清理逻辑。数据库旧二维码列可为兼容既有数据库暂时保留，但业务代码不得再读取或写入。

客服弹窗验收从 `360px` 手机视口开始，检查图标、动作文字和号码均在卡片及正文边界内，左右卡片等宽等高且无额外左边距；同时覆盖长微信号、单项联系方式、平板和 PC。2026-10-17 本地 Chromium 使用拦截的联系方式响应完成上述检查，另验证 `360×480` 短屏和关闭操作；未改动数据库。此记录不代表安卓或 iOS 真机验收。
