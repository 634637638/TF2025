# 快捷键规范

全局或跨页面快捷键统一使用 `useKeyboardShortcut`。该 composable 支持响应式启用条件、修饰键、忽略输入/可编辑区域、阻止默认行为，并在 Vue effect scope 销毁时移除监听。

弹窗内的 Escape、表格单元格导航、扫码输入等局部键盘交互可以在组件内部处理，但必须随组件生命周期添加/移除监听，不得注册永不清理的匿名全局监听。新增快捷键应避免与浏览器、操作系统和常用输入操作冲突，并在对应 UI 提供可发现的提示。

快捷键中不得记录或传输用户输入内容。避免在文本框输入时触发应用命令；确实需要时必须显式设置 `ignoreEditable: false` 并说明原因。

```bash
cd frontend
npm run check:shortcuts
```
