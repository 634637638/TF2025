# 响应式与主题视觉回归清单

本清单用于补足静态审计无法判断的布局、遮挡、触摸和颜色问题。每次调整公共 Dialog、表格、页面壳、断点或主题令牌时，至少执行本清单中相关页面的回归；不能以 `check:responsive` 或 `check:theme` 通过替代浏览器验证。

## 视口矩阵

| 设备类别 | CSS 视口 | 重点检查 |
| --- | --- | --- |
| 窄手机 | 375 × 812 | 单列布局、弹窗边距、4 个及以上页头操作单行横滑、键盘/安全区遮挡 |
| 大手机 | 430 × 932 | 内容密度、列表操作区、底部固定操作 |
| Android 手机 | 360/412 CSS px | Chrome 软键盘、`adjustResize`、横向溢出、底部操作区 |
| iPhone | 375/393/430 CSS px | Safari 地址栏动态高度、`visualViewport`、刘海和 Home Indicator 安全区 |
| 平板竖屏 | 768 × 1024 | 手机与桌面布局切换、Dialog 最大宽度、表格横向滚动 |
| 平板横屏 | 1024 × 768 | 弹窗高度与滚动、筛选区列数、操作列可用空间 |
| 桌面 | 1440 × 900 | 页面最大宽度、表格列和弹窗比例、浮层层级 |

浏览器开发者工具应使用设备模拟和实际 CSS 视口；不能只按物理屏幕分辨率推断 CSS 像素。

## 必测页面与交互

1. `/query`：打开设备详情、设备销售信息和编辑弹窗；验证弹窗随手机、平板和桌面变化，内容区可滚动，页头标题与按钮垂直居中、操作保持单行并可滑到最右侧，底部操作不重叠。
2. `/inventory`：检查搜索折叠、主表横向滚动、操作列以及空数据和加载状态。
3. `/sales`：同时检查默认图文卡片与表格模式，双击进入同一字段/权限口径的详情，操作只在底部；检查销售表单、结算/编辑弹窗、金额输入和移动端底部操作区。
4. `/price-query`：验证查询密码后双击打开在库商品详情，关闭后确认没有重新出现或留下无法关闭的外壳，仍可主动再次打开；电脑窄窗口和平板、手机一并检查。确认日期按北京时间显示且日期-only 字段不发生跨日。
5. 任一权限管理页面：检查窄屏下长权限项、树形内容及确认弹窗，不允许横向撑破视口。
6. `/price-query`、`/sales-price-display`：分别从 Safari 标签页和主屏幕书签打开保存图片弹窗；检查三个按钮的上下间距一致，竖屏刘海和 Home Indicator、横屏左右安全区均在弹窗外层避让，长图片正文可滚动。自动回归入口为 `test:dialog-widths -- --safe-area-only`，真机仍须单独记录。
7. 报价页头：在 `/price-query` 输入密码前后检查两按钮/四按钮，切换全部型号、二手机加载与保存图片生成状态；`/sales-price-display` 检查保存及生成中状态。320/360px 四按钮按两列完整显示，375px 及以上按公共容器换行；每排按钮在背景内居中，每个按钮图文靠近且居中，不隐藏图标、不裁切文字、不横向溢出。`/standards` 检查同一公共参数预览；自动入口为 `test:dialog-widths -- --price-header-only`，不替代真实 iOS/Android 验收。

8. 菜单图标：在桌面及 360px 窄屏搜索并选择在线图标，检查当前页批量预览 SVG 可见、失败提示及重试、在线翻页不请求本地目录、快速换关键词旧结果不覆盖。等待保存期间旧值保留、菜单保存禁用；模拟保存失败后可重试。重新打开页面，在阻断浏览器外站图标资源时在线候选仍通过站内预览、已入库 SVG 仍正常显示，历史缺失项显示本地占位；检查侧栏、手机菜单、页签、标题和权限图标对齐及颜色继承。
9. 公共媒体预览：手机横竖屏下图片按比例铺满可用屏幕，无左右箭头及缩放工具；横滑切换图片/视频，双指缩放和连续拖动不误翻页。普通只读预览顶部仅保留关闭，有下载/删除权限时显示对应操作；长文件名不挤走计数和关闭，刘海及横屏安全区内按钮可点击，放大图片也不覆盖关闭，关闭后滚动锁正常释放。视频原生控件避开底部安全区，拖动进度条不翻页；桌面继续显示切换和缩放工具。自动入口 `test:dialog-widths -- --media-only`，另验 Android Chrome、iOS Safari 与主屏幕书签。

10. 公共金额输入：在手机和桌面验证整数 `225` 不补 `.00`、`225.02` 保留、`225.20` 完成编辑显示 `225.2`；逐字输入小数、粘贴、清空、只读/禁用和最小/最大值不丢失原语义。批量销售同时检查逐台利润与汇总联动、800px 声明下的表格/卡片布局，以及 IMEI 红色标签和号码原色。

11. 批量操作尺寸：`/payments` 手机选择栏使用 `data-size="small"`，核对 28px 高度、左右 8px、文字及图标 12px；PC 恢复公共默认。`/standards` 对照默认与小号组，在浏览器移除小号声明应恢复默认，相邻组不受影响；颜色、权限、点击与原有横向滑动保持正常。其他未声明的批量操作组继续读取公共默认令牌。

12. `/subsidy` 编辑弹窗：手机常规字段两列、标签置顶，长字段整行；权限隐藏后的单字段行自动铺满，禁用字段不变为可编辑。验证 320–430px 输入框、日期和 15 位 IMEI 不撑出正文，销售店铺下无重复提示；平板/PC 保留横向标签与两列，滚动正文可访问备注和底部保存/取消。双击详情的客户、设备、销补和状态区在手机/PC 均每行两个字段，长身份证、IMEI、门店名称完整换行，权限隐藏后不保留空占位。

13. 公共弹窗宽度：桌面未声明尺寸时默认 800px，百分比及内容自适应宽度默认上限 800px；显式宽度、独立 `maxWidth` 和档位继续优先。检查 360–1920px、明暗主题及动态移除声明后的默认回退，手机和平板仍遵循公共视口边界。国补详情、内存选择、综合查询素材管理、报价图片保存和商城弹窗均不得恢复 `90%` 声明；检查手机左右各 4px 的公共边界，以及桌面 500/600/700px 档位仍生效。自动入口为 `test:dialog-widths`，不代表所有业务页面逐页或真机验收。

14. `/stores` 与查看类弹窗：门店详情无底部“关闭”及空 footer，顶部关闭正常；PC/平板/手机点击外部遮罩关闭，点击正文、从正文拖到遮罩、手机滑动及指针取消不误关闭。新增/编辑门店和其他待提交表单点击遮罩保留草稿；照片/商品管理只读时可关闭，有编辑权限时保留待保存内容。详情、明细、历史和报价保存预览均复用公共关闭入口。

15. H5 `/m/login`、`/m/register` 与 `/m/order-query`：首次点击提交即显示字段错误；非法手机号、空白姓名、密码不一致和未同意协议均不发业务请求。登录/注册共用认证卡片，375–1440px 不溢出，手机协议文字换行。公共金额拒绝科学计数和中英文混输粘贴，逐字小数、清空和边界保留；薪资两类销售明细的宽表可横向滚动、关闭可达。自动入口 `test:input-flows`；加 `-- --ios` 使用 Xcode iPhone 模拟器，仍须单列实际键盘、主屏幕和真实设备结果。

16. 公共覆盖层补验：`test:input-flows -- --overlays`，追加 `--ios` 使用 Xcode Safari。检查姓名取消/并发/保存失败重试，弹窗反复开关、嵌套Escape及最终计算滚动样式，30张图片索引与合成手势，媒体上的删除确认按钮实际可点击，以及销售/批发真实页头与长图保存弹窗。不要用程序调用按钮成功代替点击命中检查；系统分享、主屏幕保存、视频控件与实际软键盘仍分开记录。明暗主题使用正式 `data-theme` 属性。

17. 表格等待互斥：`test:input-flows -- --loading-only`，追加 `--ios` 检查 Xcode Safari。保留路由懒加载的样式注入顺序，验证首载只显示读取占位、空表/保留数据刷新只显示区域遮罩、隐藏占位不丢高度、完成或失败后无动画残留；每种主题只允许一个可见等待。公共入口通过不代表所有业务页面逐页验收。

18. `/customers` 新增/编辑与详情：新增/编辑手机短字段每行两个、标签置顶；邮箱、证件、详细地址、Apple ID、密码及备注整行；五级地区内省/市、县区/乡镇两列，村委会/社区及版本提示整行。检查权限隐藏后单字段补满、禁用不变、长错误不覆盖下一行、桌面账户三列与手机两列切换；新增/保存及取消保留，编辑遮罩不关闭。详情无底部“关闭”及空 footer，顶部和外部遮罩可关闭、正文点击不误关闭。详情手机/平板短字段、账户统计及短联系方式每行两项；身份证、邮箱、地址、地区、Apple ID及备注整行换行，长数字不挤出卡片。隐藏部分字段及仅留单字段时不出现占位内容，单字段铺满；767/768、1024/1025px边界均检查，桌面保留左右分区，顶部关闭和正文滚动可用。布局测试使用合成客户与本地页面模板，避免写入云端业务样本。

每个页面至少验证：初始加载、数据为空、长文本/长表格、弹窗打开与关闭、表单校验、加载中、操作成功/失败提示。只有实际存在对应状态时才需触发，不通过修改线上数据制造测试状态。

在 Android Chrome 和 iOS Safari 额外验证：聚焦输入框后页面内容仍可滚动、底部 FAB/固定按钮不被软键盘遮挡、关闭键盘后页面高度恢复、旋转屏幕后弹窗和列表不残留旧高度。支持 `100dvh` 的浏览器使用动态视口，旧浏览器回退到 `100vh`。

## 明暗主题

在上述页面分别切换浅色和深色主题，检查页面背景、正文/辅助文字、边框、输入控件、表格悬停、禁用态、遮罩和 Toast 的对比度；确认抽屉、Popover、日期选择器等 Teleport 浮层跟随当前主题。刷新页面后还要验证主题持久化与系统主题设置符合预期。

## 记录方式

回归记录包含提交版本、浏览器/设备、CSS 视口、主题、页面与交互、结果，以及缺陷截图。修复公共样式时，至少复测本清单中受影响的全部视口；只改页面私有样式时，复测对应页面和相邻断点。

当前仓库的规范门禁是静态检查，不会自动生成浏览器截图或证明视觉通过。真实设备回归结果应作为发布/PR 检查记录，不得把人工未执行的项目标记为通过。

## 手机记录详情与字段密度

- 按页面台账覆盖业务主列表及管理子列表；375/430/767/768/1024/1440px 检查明暗主题，不能只测近似组件后宣称逐页通过。
- 单击、滑动、跨行轻触和控件点击不打开详情；双击当前分页记录只打开一次，弹窗不会被兼容点击立即关闭。
- 手机操作只在查看模态框底部，按钮显隐与原权限及状态一致；只读仍能查看允许字段，无动作无空 footer。已发工资、核心模块、已完成业务不恢复危险动作。
- 新增、编辑、查看的短字段每行两个，地址、备注、长号码和复杂控件整行；字段隐藏可补位，长内容不裁切，键盘与长内容内部滚动可达。
- 母子规则、批量草稿、设置和只读关联流水按实际用途验证，不将数据展开误当按钮展开删除。
- 记录测试数据来源、实际页面/组件、视口、主题和设备；浏览器模拟与 iOS/Android 真机分别报告。
