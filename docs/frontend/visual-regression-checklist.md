# 响应式与主题视觉回归清单

本清单用于补足静态审计无法判断的布局、遮挡、触摸和颜色问题。每次调整公共 Dialog、表格、页面壳、断点或主题令牌时，至少执行本清单中相关页面的回归；不能以 `check:responsive` 或 `check:theme` 通过替代浏览器验证。

## 视口矩阵

| 设备类别 | CSS 视口 | 重点检查 |
| --- | --- | --- |
| 窄手机 | 375 × 812 | 单列布局、弹窗边距、4 个及以上页头操作单行横滑、键盘/安全区遮挡 |
| 大手机 | 430 × 932 | 内容密度、列表操作区、底部固定操作 |
| Android 手机 | 360/412 CSS px | Chrome 软键盘、`adjustResize`、横向溢出、底部操作区 |
| iPhone | 375/393/430 CSS px | Safari 地址栏动态高度、`visualViewport`、刘海和 Home Indicator 安全区 |
| 平板竖屏 | 768 × 1024 | 手机与桌面布局切换、Dialog 最大宽度、表格横向滚动 |
| 平板横屏 | 1024 × 768 | 弹窗高度与滚动、筛选区列数、操作列可用空间 |
| 桌面 | 1440 × 900 | 页面最大宽度、表格列和弹窗比例、浮层层级 |

浏览器开发者工具应使用设备模拟和实际 CSS 视口；不能只按物理屏幕分辨率推断 CSS 像素。

## 必测页面与交互

1. `/query`：打开设备详情、设备销售信息和编辑弹窗；验证弹窗随手机、平板和桌面变化，内容区可滚动，页头标题与按钮垂直居中、操作保持单行并可滑到最右侧，底部操作不重叠。
2. `/inventory`：检查搜索折叠、主表横向滚动、操作列以及空数据和加载状态。
3. `/sales`：检查销售表单、结算/编辑弹窗、金额输入和移动端底部操作区。
4. `/price-query`：验证查询密码后双击打开在库商品详情，关闭后确认没有重新出现或留下无法关闭的外壳，仍可主动再次打开；电脑窄窗口和平板、手机一并检查。确认日期按北京时间显示且日期-only 字段不发生跨日。
5. 任一权限管理页面：检查窄屏下长权限项、树形内容及确认弹窗，不允许横向撑破视口。
6. `/price-query`、`/sales-price-display`：分别从 Safari 标签页和主屏幕书签打开保存图片弹窗；检查三个按钮的上下间距一致，竖屏刘海和 Home Indicator、横屏左右安全区均在弹窗外层避让，长图片正文可滚动。自动回归入口为 `test:dialog-widths -- --safe-area-only`，真机仍须单独记录。
7. 报价页头：在 `/price-query` 输入密码前后检查两按钮/四按钮，切换全部型号、二手机加载与保存图片生成状态；`/sales-price-display` 检查保存及生成中状态。320/360px 四按钮按两列完整显示，375px 及以上按公共容器换行；每排按钮在背景内居中，每个按钮图文靠近且居中，不隐藏图标、不裁切文字、不横向溢出。`/standards` 检查同一公共参数预览；自动入口为 `test:dialog-widths -- --price-header-only`，不替代真实 iOS/Android 验收。

8. 菜单图标：在桌面及 360px 窄屏搜索并选择在线图标，检查当前页批量预览 SVG 可见、失败提示及重试、在线翻页不请求本地目录、快速换关键词旧结果不覆盖。等待保存期间旧值保留、菜单保存禁用；模拟保存失败后可重试。重新打开页面，在阻断浏览器外站图标资源时在线候选仍通过站内预览、已入库 SVG 仍正常显示，历史缺失项显示本地占位；检查侧栏、手机菜单、页签、标题和权限图标对齐及颜色继承。

每个页面至少验证：初始加载、数据为空、长文本/长表格、弹窗打开与关闭、表单校验、加载中、操作成功/失败提示。只有实际存在对应状态时才需触发，不通过修改线上数据制造测试状态。

在 Android Chrome 和 iOS Safari 额外验证：聚焦输入框后页面内容仍可滚动、底部 FAB/固定按钮不被软键盘遮挡、关闭键盘后页面高度恢复、旋转屏幕后弹窗和列表不残留旧高度。支持 `100dvh` 的浏览器使用动态视口，旧浏览器回退到 `100vh`。

## 明暗主题

在上述页面分别切换浅色和深色主题，检查页面背景、正文/辅助文字、边框、输入控件、表格悬停、禁用态、遮罩和 Toast 的对比度；确认抽屉、Popover、日期选择器等 Teleport 浮层跟随当前主题。刷新页面后还要验证主题持久化与系统主题设置符合预期。

## 记录方式

回归记录包含提交版本、浏览器/设备、CSS 视口、主题、页面与交互、结果，以及缺陷截图。修复公共样式时，至少复测本清单中受影响的全部视口；只改页面私有样式时，复测对应页面和相邻断点。

当前仓库的规范门禁是静态检查，不会自动生成浏览器截图或证明视觉通过。真实设备回归结果应作为发布/PR 检查记录，不得把人工未执行的项目标记为通过。
