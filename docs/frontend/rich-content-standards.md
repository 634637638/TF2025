# 富文本内容统一规范

## 公共入口

跨页面富文本统一使用 `frontend/src/components/RichTextEditor.vue` 编辑、`RichContent.vue` 展示。经验分享、站内公告和 DH 公告都通过这两个入口共享工具栏、媒体插入体验、手机端布局及前端 HTML 净化。业务页面只提供权限适配的 `uploadMedia(file, kind)`，不复制编辑器配置或展示净化逻辑。

编辑器按需加载 wangEditor；公共编辑器组件进入页面时即启动依赖加载，编辑器和工具栏共用同一个加载任务，避免弹窗打开后首次点击仍被依赖加载阻塞。上传适配器返回媒体 URL；公共内容媒体接口为 `POST /api/content-media`，接受单个图片或视频文件，要求 `system:edit` 或 `guide:edit`。经验分享继续使用 `/api/shared/upload`，保留其私有附件签名与文章归属检查。

工具栏由公共 `toolbarKeys` 配置控制：标题、粗体/下划线/斜体、列表、对齐、链接、图片、视频、撤销/重做和全屏作为主操作；字体、颜色、行高、引用、缩进、表格、代码、分隔线和表情放入“更多格式”。“更多格式”菜单限制最大宽高并允许内部滚动，不能被编辑器容器或弹窗边界裁切；手机端工具栏允许换行，避免横向滚动容器裁掉弹出菜单。

编辑区使用稳定的响应式可视高度并在正文区域内部滚动，滚动边界由 `overscroll-behavior: contain` 限定；长正文不撑高弹窗，也不带动整页滚动。桌面和手机的高度、菜单尺寸由公共 `RichTextEditor.vue` 统一维护，业务页面不得复制覆盖。

普通段落使用紧凑连续排版：编辑区和展示区的段落上下外边距统一为 `0`，避免按 Enter 换段时出现大块空白。标题、引用、列表等结构继续由富文本语义和工具栏控制，不通过页面样式覆盖公共段落间距。

## 内容契约与安全

- 正文以 HTML 保存；仅允许段落、标题、列表、引用、强调、链接、图片、视频、音频、表格和必要的编辑器结构属性。
- 后端统一调用 `backend/src/utils/sanitize-rich-content.js`；写入前净化，前端展示统一经过 `RichContent.vue` 和 DOMPurify。业务页面不得直接将数据库 HTML 传给 `v-html`。
- 链接与媒体 URL 仅允许 HTTP(S)、`mailto:`、`tel:` 及仓库约定的上传路径。链接强制 `noopener noreferrer`；事件属性、脚本、iframe、对象和危险协议必须移除。
- 公开公告媒体存放在公开静态目录 `uploads/content-media`，只用于明确公开的内容；私有经验分享媒体继续由共享文件签名接口访问，不得改成公开静态资源。
- 服务端限制正文长度、媒体类型和上传大小。页面上传权限不得替代后端鉴权与文件签名校验。
- 旧纯文本内容继续按文本显示，不执行 HTML；移动端展示图片、视频和表格时不得撑破内容宽度。

## 新页面接入

1. 复用 `RichTextEditor`、`RichContent` 及 `sanitize-rich-content.js`。
2. 为业务上传实现权限受控的适配器；复用内容媒体接口或现有私有媒体接口，不新增独立编辑器配置。
3. 把字段长度、媒体可见范围和过期清理纳入业务接口契约。
4. 更新业务 API/权限文档与页面功能台账；执行前端类型、定向 ESLint、响应式、UI、组件采用、后端契约和安全检查。
