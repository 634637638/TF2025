# 报价页联系方式统一规范

销售报价和批发报价的联系方式必须使用相同的 DOM 契约和全局样式，不得在页面内分别维护手机号卡片布局。

## 布局要求

- 联系人卡片继续使用两列网格，列宽使用 `minmax(0, 1fr)`，防止窄屏内容把页面撑出横向滚动。
- 每个联系人项目使用姓名列和手机号列；两个背景均按内容宽度自适应，姓名和号码之间保留统一间距。
- 联系区外层保留冷灰蓝卡片底色与边框；每位联系人保留独立浅绿色小卡片，姓名和手机号分别使用轻量紫色、青绿色底纹。以上结构只由 `frontend/src/styles/components/_price-contact.scss` 控制，页面不得再保留过时的 `contact-card-legacy` 私有样式。
- 姓名和手机号文字在各自背景内居中，不能固定靠右或因内容长度改变另一侧背景；手机端必须完整显示姓名和号码，不得以省略号隐藏，所有手机宽度均保持每行两张联系人卡片，并在窄屏收紧字号和内边距。
- 姓名和手机号均使用稳定字号：桌面端姓名 `16px`、手机号 `18px`；移动端姓名 `15px`、手机号 `17px`；超窄屏再降一级。
- 联系电话必须完整展示；只有超过卡片可用宽度时才允许在号码自身区域内省略，禁止覆盖姓名或产生页面横向滚动。
- 姓名和手机号必须保持可点击电话链接，不能为了视觉布局移除 `tel:` 行为。

## 公共实现

全局样式位于 `frontend/src/styles/components/_price-contact.scss`，由 `frontend/src/main.ts` 注册，适用于销售报价和批发报价。页面私有样式只能处理业务状态或图片生成临时样式，不得重新定义联系方式的字号、网格和对齐方式。

## 默认联系人

- 系统管理 -> 报价信息 -> 报价联系人中，每行可点击“设为默认”。
- 默认联系人保存于 `public_price_default_contact`，销售报价和批发报价顶部号码及水印统一读取该联系人。
- 联系人编辑、删除后，如果原默认联系人不存在，自动回退到当前第一条；旧配置没有默认值时兼容第一条联系人。
- 联系人表格的“默认”和“操作”列必须通过 `$getActionColumnWidth` 按实际按钮文字计算，不得写固定宽度；按钮统一使用 `table-action` 及 `table-action--success`、`table-action--pin`、`table-action--edit`、`table-action--delete`、`table-action--neutral` 语义类。列内安全留白由公共表格变量统一控制，不在页面单独扩大。
- “默认”按钮存在“默认/设为默认”两种显示状态时，宽度只按最长状态的单个按钮计算（`['设为默认']`），不能把两个状态当成两个并列按钮累加。
- 操作容器统一使用 `.action-buttons`，按钮间距、尺寸、移动端收缩和列内居中由公共表格样式维护；页面不得为联系人操作区增加固定宽度、私有间距或按钮尺寸。
- 姓名、手机号码列使用公共 `getTextColumnMinWidth`，将表头和当前联系人数据纳入测量；短姓名和短号码不得使用过大的固定列宽，长号码仍必须完整展示。

## 验收

- PC 端两个联系人卡片等宽排列，手机号在号码区域居中并自动拉伸。
- Android 和 iOS 窄屏下姓名、手机号均完整可读，长号码不挤压姓名、不产生横向滚动。
- 销售报价和批发报价在相同 viewport 下联系方式字号、间距和对齐一致。
