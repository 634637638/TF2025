# 手机状态编辑规范

库存管理和销售管理的设备编辑弹窗统一使用 `frontend/src/constants/phoneStatuses.ts` 中的
`PHONE_EDIT_STATUS_OPTIONS`。该列表排除已完成交易状态：已售、调货、划拨；维修、租赁、预订、丢失、退货、损坏和可售等未完成状态继续保留。

设备状态只有一个可销售值：`in_stock`（显示为“可售”）。历史数据或旧同步数据中的 `available`/“可用”会在兼容层归并为 `in_stock`，不再作为新的状态选项或数据库状态写入。

综合查询是历史台账页面，继续使用完整的 `PHONE_STATUS_OPTIONS`，用于展示和编辑完整状态记录，不复用编辑弹窗的过滤列表。

后端仍负责最终权限和状态校验。拥有对应库存或销售编辑权限的角色可以编辑维修、租赁等未完成状态设备；没有编辑权限的用户仍会被接口拒绝。管理员不作为状态编辑的额外前置条件。状态变更为可售后，设备才进入正常销售出库流程；本规范不会直接放开已完成交易设备的销售出库。

库存和销售页面对所有未完成交易设备保留查看、编辑和删除入口；出库入口保持展示，但维修、租赁、损坏、丢失、退货等不可销售状态会禁用出库。预订设备允许出库，但必须自动带出并校验预定人的客户信息。已售、调货、划拨不进入这两个页面的待处理列表。
