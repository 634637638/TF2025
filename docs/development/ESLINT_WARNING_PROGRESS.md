## 处理规则

1. 未使用变量优先删除；确认是接口参数或预留参数时使用 `_` 前缀，并保留必要注释。
2. `any` 优先替换为具体接口、泛型或 `unknown`，在运行时边界使用类型守卫收窄。
3. 第三方全局对象的动态成员只能在声明边界登记豁免，业务代码不得扩散 `any`。
4. 每批修复后必须运行 `npm run type-check`、`npm run check:fields` 和后端契约测试。
5. 新增 warning 会由 `lint:strict` 和 `check:standards` 阻断，不允许重新增加基线。
