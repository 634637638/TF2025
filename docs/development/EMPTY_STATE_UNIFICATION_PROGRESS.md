# 全局空状态统一进度

更新时间：2026-08-28

## 本轮完成

- 新增全局公共组件 `DataEmptyState.vue`，统一 PC、手机端、表格、列表和弹窗的空状态尺寸、间距、文字与操作区。
- 定义 `empty`、`filtered`、`error`、`permission`、`initial` 五种数据状态，明确加载中、正常无数据、筛选无结果和请求失败的边界。
- 全站原有 49 个文件、76 处直接 `el-empty` 已迁移到公共组件，原有业务文案、图片和操作插槽保留。
- 基础资料、权限、报价、考勤、工资弹窗、Git、H5、销售、库存、菜单等历史页面自绘的 `.empty-state` / `.no-results` 已同步迁移；当前 81 个 Vue 文件、123 个空状态入口均使用公共组件，不再保留第二套整块空状态结构。
- `PaginatedTable` 与 `MobileTable` 已接入公共空状态；移除普通空列表默认显示的无意义刷新按钮。
- 库存表格和销售表格的私有空状态已迁移；销售筛选无结果会提供统一的“清空筛选条件”操作。
- 新增 `check:empty-states` 并接入 `check:standards`，防止后续页面重新直接使用 `el-empty` 或新增页面私有空状态结构。
- 新增权威规范 `docs/frontend/empty-state-standard.md`，并登记到规范清单。

## 保持规则

1. 新页面必须使用 `DataEmptyState`，不得自行绘制空状态。
2. API 失败必须使用 `state="error"` 并提供重试，不能伪装成空数据。
3. 加载状态必须先于空状态判断，避免请求期间闪出“暂无数据”。
4. 业务文案应准确说明对象，例如“暂无颜色数据”，视觉结构由公共组件控制。
5. 每次启动和构建均执行 `check:empty-states`，违规代码不能进入生产构建。
