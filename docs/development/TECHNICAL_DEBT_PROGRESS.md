## 完成标准

1. “已完成”必须有对应命令、自动测试或真实数据库核验记录。
2. 兼容字段只代表迁移边界，不算统一完成；删除前必须确认仓内和外部调用方均不再使用。
3. 大页面拆分必须保持路由、权限、表单和缓存行为不变，并通过类型检查与生产构建。
4. 样式债务不能机械删除 `!important` 或合并不同语义颜色；第三方结构覆盖必须保留理由。
5. 包体积优化以首屏加载和路由分包结果为依据，不以删除业务依赖作为完成手段。
