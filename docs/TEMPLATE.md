# 文档标题

一句话说明文档的用途、适用对象或适用范围。

## 概述

说明读者需要了解的背景；不需要的章节可直接删除。

## 操作或规则

按实际任务描述前提、步骤、约束和预期结果。只有与代码或部署状态有关且已实际核对的内容才填写核实日期。

## 验证

列出可重复执行的检查命令或人工验证步骤。没有执行的检查应标为“未验证”，不要写成已通过。

## 相关资料

- 相关文档：填写已确认存在的相对路径链接；没有相关文档时删除本行。
- 仓库源码路径使用行内代码，例如 `backend/src/routes/example.js`

文档结构规范见[文档编写与维护规范](guides/DOCUMENTATION_STANDARDS.md)。不适用的章节可删除；不强制添加版本号、维护者、目录或更新日志。
