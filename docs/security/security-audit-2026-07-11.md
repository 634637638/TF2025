# TF2025 安全与稳定性审计记录（2026-07-11）

## 已修复高风险问题

1. 数据库同步接口仅校验登录，没有功能权限；数据预览允许把 `where` 和 `orderBy` 直接拼入 SQL。
   - 整组接口增加 `data-check:edit` 权限。
   - 移除任意 SQL 条件，限制分页范围。
   - 表名和映射字段使用标识符白名单并验证表存在。
2. 数据导入接受客户端传入的任意服务器 `filePath`。
   - 文件必须位于 `uploads/import`，并通过真实路径边界校验。
   - Excel 限制为 10MB、50000 行、200 列。
3. 通用临时文件删除接口只要求登录，可删除任意已知上传文件。
   - 仅允许 `subsidy`、`shop` 临时清理场景。
   - 按目录校验对应编辑权限，仅允许删除近期文件。
   - 商城删除接口改用统一安全路径解析。
4. SVG 图标使用正则处理后直接通过 `v-html` 渲染。
   - 前端改用 DOMPurify SVG 配置。
   - 后端入库前移除危险 SVG 标签、事件和外部链接。
5. 数据导入自动创建员工时使用固定密码 `123456`，并写入日志。
   - 改用随机高强度临时密码，不记录凭据；账号使用前由管理员重置密码。
6. 备份与上传路径方法缺少服务层边界校验。
   - 备份服务内部验证文件名。
   - 上传路径统一使用 `path.resolve` 和 `path.relative` 约束根目录。
7. 数据库连接失败后仍记录成功并返回健康状态。
   - 正确处理连接函数的布尔结果。
   - 数据库断开时跳过依赖数据库的定时任务。
   - `/api/health` 在数据库断开时返回 `503`。
8. 遗留 `/api/data` CRUD 接口和操作员列表接口未鉴权。
   - 数据 CRUD 按查看、编辑、删除操作增加 `data-check` 权限。
   - 操作员列表要求销售或库存查看权限，并只返回页面所需字段。
9. 在库查询密码可被绕过，公开库存接口泄露 IMEI、序列号和采购成本。
   - 密码验证增加严格限流，并签发 10 分钟有效的专用查询令牌。
   - 库存明细必须验证专用令牌，响应移除采购成本、备注等无关字段。
10. 匿名接口可修改全局菜单宽度，开发临时接口可在开启后匿名提权。
   - 菜单宽度只保留公开读取，写入改走登录接口。
   - 临时提权和迁移接口即使显式开启，也必须通过管理员权限校验。
11. 连接池监控把价格同步的长期锁连接误报为泄漏，销毁连接后可能残留跟踪记录。
   - 长期锁连接增加用途标记并跳过泄漏告警。
   - 包装连接销毁方法，确保同步清理活动连接记录。
12. 认证与权限调试日志输出 Token 片段和完整权限列表。
   - 不再记录任何 Token 内容、用户名或权限明细，仅保留用户 ID 和数量摘要。

## 剩余风险

### XLSX

当前 `xlsx` npm 包存在原型污染和 ReDoS，且 npm 没有可用修复版本。本次已增加路径、文件大小和工作表规模限制，但无法完全消除解析恶意工作簿的风险。

后续应将用户上传解析迁移到隔离 worker/子进程并设置超时和内存限制，或替换为持续维护的 Excel 解析库。替换完成前，Excel 导入权限只应授予受信任管理员。

### 开发工具链

完整依赖审计仍会报告 Vite/Rollup、glob 匹配工具等开发依赖漏洞。这些依赖不进入生产运行时，但应在新版本兼容验证后持续升级。

### 临时文件所有权

当前临时删除已增加模块权限、目录和时间限制。更完整的方案是上传时签发绑定用户和文件的一次性清理凭证，保存成功后作废，彻底阻止同模块用户删除他人近期文件。
