# H5 订单查询临时风险记录

截至 2026-09-30，当前实现仍保留通过手机号和下单姓名精确查询订单；当前尚未接入短信验证码。本文是现行安全边界记录，不是已完成短信认证的说明。

该方式不是可靠的强身份认证。匹配成功后，服务端按 `backend/src/utils/order-access.js` 的 `TOKEN_TTL_SECONDS` 为每笔订单签发有效期 24 小时的访问凭证，可用于查看订单详情、确认付款或取消待付款订单。订单自身的待支付过期时间也是 24 小时，但它与访问凭证有效期是两个独立规则。知道或猜中姓名与手机号的人可能取得相应订单操作能力，因此这是业务确认接受的临时风险，不应描述为短信验证或等强认证。

当前补偿控制：

- 查询接口按来源 IP 限制每 5 分钟最多 30 次。
- 同一来源 IP 与手机号组合每 15 分钟最多查询 10 次；更换网络或离开归属地不会改变业务查询条件，但会影响该 IP 维度的限流计数。
- 订单操作仍须提供签名订单凭证；订单状态及订单有效期由服务端再次校验。
- 安全审计将该接口登记为经业务确认的公开例外，保留风险说明，不把它误报成已认证路由。

后续接入短信验证或其他可靠的持有因素验证后，应移除此公开例外，并评估是否缩短订单访问凭证有效期。
