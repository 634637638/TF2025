# 备注字段一致性修改总结

> **维护日期**: 2026-10-10
> **修改目标**: 确保备注字段在库存管理、销售管理和出库流程中的一致性

## 问题描述

之前系统中备注字段在库存管理、销售管理和出库流程中存在不一致的问题：
1. 在库存管理编辑时修改备注，销售管理页面编辑时无法正常显示
2. 销售出库时，备注字段没有正确保存到 phones 表和 sales 表
3. 备注字段在不同页面之间没有正确同步

## 当前统一规则

`phones.remarks` 是设备备注的主数据；`sales.remarks` 是销售记录中的同步副本。库存编辑、销售管理编辑和销售出库都必须通过统一接口维护，不能由页面分别直接写库。

1. 库存管理或销售管理编辑备注时，`/api/phones/:id` 以本次成功提交的内容更新 `phones.remarks`，并同步该设备的销售记录备注。
2. 编辑提交为空字符串时表示清空备注，库存和销售记录都会清空。
3. 单台销售出库时，表单保留原备注表示未修改，删除备注并提交空值表示明确清空；未提交备注字段才沿用出库前设备的 `phones.remarks`。最终值同时写入新建的 `sales.remarks` 和已售设备的 `phones.remarks`。
4. 同一设备的库存编辑、销售编辑或出库操作按成功提交顺序生效，后一次成功保存的内容覆盖前一次内容；并发请求以数据库事务完成顺序为准。
5. 批量销售逐台计算最终备注：批量表单有新备注时统一覆盖，表单为空时每台设备保留自己的原备注。

## 修改内容

### 前端修改

#### 1. SalesView.vue - 销售管理页面

**修改位置**: `openSaleModal` 函数

**修改内容**: 在打开销售模态框时，初始化备注字段为手机的备注信息

```javascript
// 打开销售模态框
const openSaleModal = (phone: Phone) => {
  // ... 其他代码 ...

  // 初始化备注：加载手机的备注信息
  saleForm.remarks = phone.remarks || phone.purchase_remarks || ''

  // ... 其他代码 ...
}
```

**修改位置**: `openQuickSale` 函数

**修改内容**: 在快速销售模式下，初始化备注字段

```javascript
// 单台模式
selectedPhone.value = availablePhones.value[0]
saleForm.sale_price = ''
saleForm.purchase_cost = String(availablePhones.value[0].purchase_cost || 0)
// 初始化备注：加载手机的备注信息
saleForm.remarks = availablePhones.value[0].remarks || availablePhones.value[0].purchase_remarks || ''
showSaleModal.value = true
```

### 后端修改

#### 2. sales.js - 销售路由

**修改位置**: `/api/sales/phone` POST 接口

**修改内容**: 销售出库先在事务中锁定并读取设备备注，计算每台设备的最终备注后，同时写入 `sales` 和 `phones`，避免空备注导致两张表不一致。

```javascript
const requestedRemarks = String(remarks ?? '').trim()
const shouldApplyRequestedRemarks = hasRemarksField && (!isBatchSale || requestedRemarks !== '')
final_remarks = shouldApplyRequestedRemarks
  ? (requestedRemarks || null)
  : (phoneRemarksMap.get(phoneId) || null)
```

## 备注字段流程

### 库存管理流程

1. **入库时**: 用户可以在入库单上填写备注信息
2. **编辑时**: 用户可以在库存管理页面编辑商品的备注信息
3. **保存**: 备注信息保存到 `phones` 表的 `remarks` 字段

### 销售管理流程

1. **查看商品**: 在销售管理页面，可以查看商品的备注信息
2. **编辑商品**: 在编辑弹窗中可以修改备注信息，同步更新到 `phones` 表
3. **销售出库**:
   - 如果用户在销售表单中输入了备注，使用新备注
   - 如果用户未修改单台销售表单中的备注，保留商品的原始备注
   - 如果用户在单台销售表单中删除备注，清空商品和销售记录备注
   - 备注同时保存到 `phones` 表和 `sales` 表

### 出库流程

1. **加载备注**: 销售模态框打开时，自动加载商品的备注信息
2. **修改备注**: 用户可以根据需要修改备注
3. **保存备注**: 销售时，备注信息保存到 `phones` 表和 `sales` 表

### 测试场景 1: 库存管理编辑备注

2. 修改备注信息（例如："此商品有划痕，销售时请注意"）
3. 保存修改

### 测试场景 2: 销售管理查看备注

1. 在销售管理页面找到同一个商品
2. 点击编辑按钮
3. 验证：编辑弹窗中的备注字段显示与库存管理中一致

1. 在销售管理页面选择一个商品进行销售

5. 完成销售
6. 验证：
   - 在销售记录中可以看到修改后的备注

   - 在商品详情中备注保持不变

## 注意事项

1. **批量销售**: 在批量销售模式下，如果多台商品的备注不同且表单备注为空，每台设备保留自己的原备注；填写新备注后，统一覆盖本批次设备备注。

2. **备注覆盖**: 如果在销售时输入了新的备注，新的备注会覆盖商品的原始备注。库存编辑、销售编辑和销售出库遵循相同的最后成功保存规则。

3. **备注长度**: 备注字段最大长度为 500 个字符，前端会进行字数限制提示。
